# Лаборатория продаж — GitHub Pages

Полностью статическая версия сайта, подготовленная для публикации по адресу:

`https://andriyanov0305.github.io/laboratoriya-prodazh/`

## Публикация

1. Создайте в GitHub публичный репозиторий `laboratoriya-prodazh`.
2. Загрузите **содержимое этой папки** в корень ветки `main` (файл `index.html` должен лежать в корне репозитория).
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. После публикации откройте адрес выше. Первое развёртывание обычно занимает несколько минут.

## Структура

- `index.html` — страница сайта;
- `assets/css/styles.css` — стили;
- `assets/js/app.js` — квиз, расчёт результата и подготовка заявки;
- `favicon.svg` — иконка сайта;
- `.nojekyll` — отключает обработку Jekyll.

Все пути к локальным ресурсам относительные и работают в подпапке `/laboratoriya-prodazh/`.

## Внешние зависимости

Сайт не использует библиотеки, CDN, внешние шрифты, сборщик или сервер. Для открытия и GitHub Pages достаточно файлов из архива.

Внешние переходы используются только после явного выбора посетителя:

- `mailto:` — подготовка письма;
- `tg://` — открытие Telegram;
- `https://max.ru/` — открытие MAX;
- `tel:` — звонок по номеру телефона.

## Ограничения статической версии

Серверные функции ChatGPT Sites не используются и не требуются. Данные формы не сохраняются на сайте: браузер подготавливает текст заявки, а посетитель сам отправляет её через Email, Telegram или MAX.

Если позже понадобится автоматическая отправка формы без открытия приложения пользователя, подключите внешний обработчик форм (например Formspree) или собственный API. Не размещайте секретные ключи в JavaScript.
